# Loom

[English](README.md)

在浏览器中搭建数字电路。从逻辑门开始，将电路封装成可复用元件，搭建并编程控制一台可编辑的 8 位计算机。引导课程从信号和与非门逐步延伸到 CPU 和计算器。

## 可以做什么

- **搭建电路：** 在画布上连接逻辑门、总线、寄存器、内存和三态缓冲器。
- **复用元件：** 将电路封装到元件库，用于更大的设计。
- **编程控制计算机：** 编辑 CPU 电路，汇编程序，连接键盘、终端和七段数码管。程序通过实际的电路仿真执行。
- **测试与调试：** 保存输入输出测试，回放失败用例，查看信号历史并设置断点。也可以用 CLI 验证和测试导出的工程。

## 本地运行

需要 Bun 1.4.2 和 Node.js 24 或更新版本。

```sh
git clone https://github.com/tacshi/Loom.git
cd Loom
bun ci
bun run dev
```

使用桌面浏览器打开 `http://127.0.0.1:5173`。

## 开始使用

打开 **学习 → 开始课程**，完成 60 个主线任务和 40 个选做项目。每个任务先介绍概念，并提供可选的提示和示例。点击 **运行测试** 检查解法，通过后解锁下一个任务。

体验完整的计算机：

1. 打开 **打开示例… → Loom 8 CPU**。
2. 点击 **汇编并加载**，再点击 **运行时钟**。自带的求和程序会输出 **55**。
3. 在 **电路** 中定位元件、打开子电路，或在 **调试** 中查看输入和输出。

打开 **Loom 8 I/O · 计算器**，可以通过键盘和终端进行十进制加减运算。也可以新建空白工程，自由搭建电路。

## 保存与离线使用

通过 **工程管理 → 导出文件** 保存 `.loom.json` 副本，再用 **导入文件** 在其他浏览器或设备中打开。工程存储与网站地址及端口绑定：开发服务器（`5173`）与生产预览（`4173`）使用独立存储。清除网站数据会删除本地工程。

生产构建在首次成功联网加载后可离线使用。构建并预览：

```sh
bun run build
bun run preview
```

自行托管请参阅[部署文档](docs/DEPLOYMENT.md)。

Loom 仍在开发中，仅支持当前工程格式。不兼容的文件会被拒绝，不会修改原文件或替换已打开的工程。

## 开发

```sh
# 快速测试
bun run test:fast

# 类型检查并构建应用和 CLI
bun run build
```

运行单个测试文件：`bun run test tests/component-label.test.ts`。完整测试与浏览器检查按需运行，详见[测试文档](docs/TESTING.md)。
